# КПшка Desktop для Windows

Тендеры, закупочные процедуры и деловые сообщения — в одном приложении.

![КПшка Desktop](https://kpshka.ru/downloads/windows/press/cover-wide.png)

**[Скачать для Windows](https://github.com/pynikov/kpshka-desktop-releases/releases/latest)** · [Официальный сайт](https://kpshka.ru/) · [Прямая загрузка EXE](https://kpshka.ru/downloads/windows/Kpshka-0.1.0-win-x64.exe)

## Возможности

- Поиск тендеров по ключевым словам, региону, закону, цене и срокам.
- Расширенные фильтры, исключения, заказчики, ОКПД2 и площадки.
- Шаблоны поиска и избранные закупки.
- Закупочные процедуры, запросы с вложениями, вопросы и предложения.
- Переписка с компаниями и поиск сообщений.
- Общий аккаунт с сайтом КПшка.ру.

Гостевой режим позволяет познакомиться с поиском. Контакты и документы доступны после регистрации с учётом прав аккаунта. Клиент скачивается бесплатно; функции онлайн-сервиса зависят от аккаунта, прав и действующих тарифов.

## Запуск

1. Скачайте `Kpshka-0.1.0-win-x64.exe` из раздела Releases или с официального сайта.
2. Запустите файл в Windows 10/11 x64. Установка приложения и отдельная установка .NET не требуются.
3. Продолжите как гость или войдите в аккаунт КПшка.ру. Для работы нужен интернет.

Сборка 0.1.0 пока не имеет цифровой подписи издателя. Скачивайте файл из официальных источников и при необходимости сверяйте SHA-256.

## English

Kpshka Desktop is a Russian-language Windows client for Kpshka.ru, a tender search and business procurement platform. It provides advanced search filters, saved templates, favorites, procurement procedures and business messaging. Guest search is available; access to contacts, documents and restricted functions requires an eligible account. The proprietary client is free to download; online service features depend on account permissions and subscription terms. Windows 10/11 x64 and an internet connection are required. This repository distributes release binaries and product information.
